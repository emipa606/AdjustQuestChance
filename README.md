Tired of getting a lot of garbage "take care of my favourite squirrel" quests, while being stuck on sea ice with no settlements around and without any resources to do a weeks-long travel to the closest settlement?

Suffer no longer!!!
This mod allows you to adjust quest weights (probabilities) to your liking, whether you want more map quests (travelling) or puppy-sitting quests (sitting on your arse and getting a new hemorrhoid).

All quest weights are configurable.
All other rules still apply: pawn limit, quest limit etc.

Notice: default mod settings are the same as game settings, so you actually have to open mod settings and drag some sliders to change quest’s chances
Notice: Reload of game save is required for the changes to apply (but no game restart required)
